# NJ Catering

Official website for **NJ Catering**, a professional catering service based in Chennai, Tamil Nadu, run by Mr. K. Sathish. We cater weddings, corporate events, birthday parties, and private family functions with authentic South Indian veg & non-veg menus across Tamil Nadu.

## Live Site
https://sanzayjanarthanan.github.io/nj-catering/

## Features
- Veg / Non-Veg / Light Stall menu toggle
- Ready-made meal packages with pricing
- WhatsApp-based booking flow
- Fully responsive, single-page design

## Tech Stack
HTML, CSS, JavaScript (no frameworks)

## Contact
For bookings, reach out via WhatsApp through the site's "Book Catering" button.
